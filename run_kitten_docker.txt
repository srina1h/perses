V8 EBPF CRASH-DETECTION (BUILD & RUN)

Build (symbolful d8 + allowlist + uprobe list at build):

sudo docker buildx build --builder isolated-builder --load \
  -f Dockerfile.ebpf \
  --build-arg CACHE_BUST=$(date +%s) \
  -t kitten_v8_ebpf .

Run (requires eBPF permissions; maps results, logs, optional custom seeds):

sudo docker run -it --init --name kitten_v8_ebpf_run --privileged -m 70g \
  -e THREADS=$(nproc) -e JVM_HEAP=16 \
  -v "$(pwd)/results:/workspace/kitten/findings_v8" \
  -v "$(pwd)/logs:/workspace/logs" \
  -v "$(pwd)/custom-seeds:/workspace/kitten_runtime/seeds:ro" \
  kitten_v8_ebpf
